Split History

Chat Completion only. Older history stays in Chat History. The most recent character reply, plus every message after it, moves to a prompt named Recent History. Drag that entry in the Prompt Manager to put the current scene somewhere else.

Example: character, you, character, you, character, you. Chat History keeps the first character, you, character, you. Recent History gets the last character reply and the you after it. If several of your messages follow that reply, all of them move with it. If the reply is last, only that reply moves.

Text Completion is unchanged. The prompt body of Recent History is managed by this extension; place it by dragging, not by editing that text.
